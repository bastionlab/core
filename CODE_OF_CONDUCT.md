# Code of conduct

This project adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in issues, pull requests, discussions and any other project space.

Reports of unacceptable behavior go to the contact in [SECURITY.md](SECURITY.md) (GitHub private reporting:
Security → Report a vulnerability). They are handled privately.
